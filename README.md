One pickup line, 200 characters at most, that a vending machine would use on a passing human — judged pairwise by an AI judge, funniest line takes the top of ten paid places.

## Run it

```sh
python3 main.py
```

The program writes one pickup line to `/output/entry.txt`:

> I've dropped a thousand snacks, but you're the first thing that's ever made my coil jam on purpose.
